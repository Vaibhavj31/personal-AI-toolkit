Use Case 04: Software Project Development

1. Task

Using AI to debug errors, understand code and improve my SwapNet software project.

2. Tool Selection

Tool: ChatGPT

Why: ChatGPT helps analyse code, explain technical errors and suggest possible solutions.

Project Technology: React, TypeScript, Supabase and Tailwind CSS.

3. Workflow

1. Identify a project issue.
2. Collect the relevant code or error message.
3. Ask ChatGPT to analyse the problem.
4. Review the suggested solution.
5. Implement the changes.
6. Run the application.
7. Test the affected functionality.

Human Gate: I review the code changes and test the application before accepting them.

4. Verification

* Check the existing project structure.
* Verify database table names and columns.
* Check TypeScript errors.
* Test application functionality.
* Check browser console errors.
* Verify that existing features still work.

5. Outcome

AI helps me understand technical problems and improve development speed. However, it can misunderstand project requirements or suggest incorrect database structures. Testing is necessary before accepting changes.
