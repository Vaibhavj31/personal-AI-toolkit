Use Case 05: Professional Communication

1. Task

Using AI to improve professional communication and write clear emails and messages.

2. Tool Selection

Tool: ChatGPT

Why: ChatGPT helps improve grammar, sentence structure and communication tone.

3. Workflow

1. Identify the purpose of the message.
2. Write the initial draft.
3. Ask ChatGPT to improve it.
4. Specify the required tone.
5. Review the generated message.
6. Make necessary corrections.
7. Send the final message.

Human Gate: I personally review and approve the message before sending it.

4. Verification

* Check grammar and spelling.
* Verify names and dates.
* Check factual information.
* Ensure the original meaning is maintained.
* Confirm that the tone is appropriate.

5. Outcome

AI helps me write clearer and more professional messages. However, generated messages can sometimes sound generic, so personal editing is important.
