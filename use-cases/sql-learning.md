Use Case 02: SQL Learning and Query Writing

1. Task

Using AI to write SQL queries, understand DBMS concepts and solve database assignments.

2. Tool Selection

Tool: ChatGPT

Why: ChatGPT explains SQL commands and generates queries. MySQL is used to verify the results.

3. Workflow

1. Understand the database question.
2. Provide the table structure.
3. Ask ChatGPT to generate an SQL query.
4. Review the query.
5. Execute it in MySQL.
6. Check the returned records.

Human Gate: I check the query and verify the result before using it.

4. Verification

* Verify table and column names.
* Check SQL syntax.
* Execute the query in MySQL.
* Check the output.
* Verify conditions and constraints.

5. Outcome

AI makes SQL easier to understand and helps me solve database problems. Sometimes generated queries contain incorrect column names or conditions, so actual execution is necessary.
